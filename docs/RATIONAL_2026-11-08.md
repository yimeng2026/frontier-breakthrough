## 2. Hahn1：跳出指数与高斯框架

### 2.1 数据、模型和协议

第三个真实数据集来自 NIST Hahn1 铜热膨胀研究，共 236 个观测。原始文件 SHA-256 为 `7e885af48e18a222033a66cb22b491f0f5bc761b652142c0d9b28132daf63956`。

冻结 `validation/hahn1-high-temperature-protocol.json` 后：

- 训练：\(x<700\)，219 个观测；
- 留出：\(x\geq700\)，17 个观测；
- 模型：\(y=(b_1+b_2x+b_3x^2+b_4x^3)/(1+b_5x+b_6x^2+b_7x^3)+e\)；
- 两个预注册起点、线性、三次多项式和训练均值基线；
- 所有 17 个最高温点均不得用于拟合、选起点或调整阈值。

全数据拟合另用于 NIST 已知答案复核，认证参数与残差标准差均通过预注册容差，未把全数据拟合当成留出证据。

### 2.2 高温外推结果

| 指标 | 数值 |
|---|---:|
| 训练 RMSE | 0.079173079 |
| 高温留出 RMSE | 0.104726472 |
| 留出／训练 RMSE 比 | 1.322754 |
| 三次多项式留出 RMSE | 12.343635 |
| 线性基线留出 RMSE | 6.231524 |
| 训练均值基线留出 RMSE | 6.740656 |
| 留出 MAE | 0.084477 |
| 留出最大绝对残差 | 0.196100 |

高温留出 RMSE 小于训练 RMSE 的 3 倍和三次多项式基线，因此预注册判据给出**有限支持**。236 个逐点预测及全部指标均由独立程序重算，最大预测差为 0。

## 3. 分母边界：区间内证明与域外反例同时保留

| 检查 | Z3 | cvc5 | 含义 |
|---|---|---|---|
| \(0\leq x\leq900\) 内分母为零 | unsat | unsat | 实验区间内不存在零根 |
| \(x\geq0\) 全域分母为零 | sat | sat | 约 1931 K 存在正根，不能宣称全域安全 |

认证分母在区间 \([0,900]\) 内最小值约为 0.9653，未发现实根；但放开区间后，求解器给出约 1931.2468 的正根。这个结果说明：**拟合成功、实验区间内分母有效和全域数学安全是三件不同的事。**

原始文件为 `validation/cvc5-hahn1-denominator.smt2`，Z3 和 cvc5 的日志、参数与限制均已保存。双求解器一致只提高明确区间内命题的实现可信度，不提高为任意有理模型的证明。
