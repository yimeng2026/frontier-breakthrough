## 2. NIST Chwirut2：首个真实数据留出闭环

### 2.1 协议与独立复现

原始数据来自 NIST/ITL StRD 的 Chwirut2 超声标定数据集，54 个观测、22 个不同金属距离。原始文件 SHA-256 为 `c37e5522a34f9a57e18d7d10f8736202eabc0c33b8e7ad0010e618db04b57411`。

在任何非线性拟合前冻结 `validation/chwirut-holdout-protocol.json`：

- 训练：金属距离 \(x<5.0\)，47 个观测；
- 留出：金属距离 \(x\geq5.0\)，7 个观测；
- 模型：\(y=\exp(-b_1x)/(b_2+b_3x)+e\)；
- 两个预注册起点、非负参数边界、训练均值与线性基线；
- 留出点不得用于拟合、起点选择、模型选择或阈值调整。

全数据拟合另用于 NIST 已知答案复核，认证参数和残差标准差均在预注册容差内通过，未把全数据拟合当成留出证据。

### 2.2 结果

| 指标 | 数值 |
|---|---:|
| 训练 RMSE | 3.224726 |
| 高距离留出 RMSE | 2.019567 |
| 留出／训练 RMSE 比 | 0.626276 |
| 线性基线留出 RMSE | 38.974764 |
| 训练均值基线留出 RMSE | 29.009060 |
| 留出 MAE | 1.759255 |
| 留出最大绝对残差 | 3.321076 |

预注册判据“留出 RMSE 小于训练 RMSE 的 3 倍且小于线性基线”通过，因此只给出**有限支持**。独立程序从 54 个逐点预测重新计算模型、基线、指标和判据，最大预测差为 0。

## 3. Z3：把可识别性问题变成可执行反例

`validation/z3-identifiability.json` 保留三组实际求解结果：

1. 在 \(b_2>0、b_3\geq0、x\geq0\) 的定义域内，否定分母恒正命题的约束为 `unsat`，因此该定义域内分母恒正。
2. 不施加符号约束时，零分母反例为 `sat`，说明模型定义域不能省略。
3. 在 \(x=0\) 时，两个不同参数三元组产生相同响应，说明单点数据不能唯一识别全部参数。

这些结果不否定 NIST 数据或有效域内的拟合，只否定过强的全域识别性主张。Z3 没有被描述为非线性指数方程的通用求解器。

## 4. 阿司匹林：身份一致不等于所有字段必须相等

冻结 PubChem CID 2244 与 ChEMBL CHEMBL25 的完整快照后，RDKit 独立重算得到：

- 规范结构和 InChIKey `BSYNRYMUTXBXSQ-UHFFFAOYSA-N` 一致；
- 分子式 `C9H8O4`、精确质量 `180.042258736 Da`、TPSA `63.60 Å²`、重原子数 13 均通过对照；
- PubChem XLogP 为 1.2，ChEMBL ALogP 为 1.31，RDKit Crippen MolLogP 为 1.3101；
- PubChem／ChEMBL／RDKit 的 HBA 分别为 4／3／3；
- PubChem／ChEMBL／RDKit 默认可旋转键分别为 3／2／2，RDKit strict 也为 2。

因此，结构身份和选择性描述符可以一致，而算法和计数口径不同。**这些差异没有被标记为造假，也没有被强行平均。** 本工作不涉及生物活性合并或临床推断。
