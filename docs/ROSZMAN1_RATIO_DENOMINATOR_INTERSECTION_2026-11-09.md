# 前沿共生第五十六阶段：Roszman1 比值—分母联合区间与保守交集

**日期**：2026-11-09  
**文档性质**：在冻结椭球和负分母符号域内解析求解 b3/(x−b4) 的线性分式支撑，再与线性支撑和第五十四阶段交集组合；不是完整四参数非线性全局最优、概率区域或独立实验。

## 1. 解析比值—分母支撑

协议提交为 `e7a4512`。第五十四阶段已经对线性部分 b1−b2x 使用联合支撑，但反正切比值仍来自独立 b3 与分母区间。本阶段处理后者，不重写任何历史结果。

对固定的可用 x，令 c 为 b3 中心、d0=x−b4 中心、参数位移为 δ，则：

\[
z(\delta;x)=\frac{c+\delta_3}{d_0-\delta_4},\qquad \delta^TC^{-1}\delta\le r^2,\qquad d_0-\delta_4<0。
\]

负分母符号门禁为 d0+r√C44<0。第 5 折不满足非零符号条件，因此**第 5 折没有有限包络**，也不进入求根、端点见证或候选评价。

在负分母下，z≥t 等价于 b3−t(x−b4)≤0，z≤t 等价于 b3−t(x−b4)≥0。对椭球支撑求极值并消去支撑方向，得到：

\[
A=d_0^2-r^2C_{44},\quad B=cd_0+r^2C_{34},\quad D=c^2-r^2C_{33},\qquad At^2-2Bt+D=0。
\]

其中 α=c−td0，q=C33+2tC34+t²C44。下界根必须满足 α≤0、α+r√q=0；上界根必须满足 α≥0、α−r√q=0。只解平方后的二次式而不检查原始分支恒等式，会接受伪根，因此两个条件都逐点复核。

这不是 Charnes–Cooper、Möbius 或独立盒放松，而是当前固定 x、固定负符号域内的解析线性分式支撑。它联合了 b3、b4，但并未同时求解线性项与比值项的共同极值。

## 2. 预测替代界与第五十四阶段交集

线性部分继续使用完整椭球支撑。反正切单调递增，因此：

\[
L_z=A_{\min}-\frac{\arctan(z_{\max})}{\pi},\quad U_z=A_{\max}-\frac{\arctan(z_{\min})}{\pi},\qquad I_z=[L_z,U_z]\cap I_{54}。
\]

线性支撑与比值支撑可能在不同参数点取得，二者相加仍然保守，但**不是完整非线性最优**。最终交集可以收紧也可以保持，不能预设普遍收紧，更不能称为全局最优。

## 4. 数值精度与失败定位

| 检查项 | 实际处理 | 保留的边界 |
|---|---|---|
| 二次根相消 | 对会相减的一支使用倒数等价形式 | 不凭普通浮点根直接生成界 |
| 分支伪根 | 检查未平方的 α±r√q 恒等式及 α 符号 | 不把平方根自动当成有效端点 |
| 冻结协方差微小非对称 | 二次型使用 C34 与 C43 的平均，即其实际对称部分 | 不改写冻结矩阵或历史结果 |
| 第 2 折存储差异 | C34−C43=-1e-12；修正后端点比值与根一致 | 不将该存储差异隐藏或称为物理差异 |
| 精度与舍入 | 80 位 mpmath、1e-24 相对余量和 nextafter 外向转换 | 不是精确有理代数证书 |
| 空交集和不可用折 | 空交集属于构造失败；第 5 折不生成有限界 | 不通过重拟合或删点补救 |

开发中的失败门禁首先揭示了约 1e-18 的端点比值残差，随后定位到第 2 折冻结矩阵交叉项的微小存储差异。修正使用真实对称二次型后，10 项数学测试与 3 项协议测试通过。该过程不改变协议、模型、折分、历史基线或数据。

## 5. 四联图与证据边界

图：`papers/63_Roszman1比值分母联合区间/fig63_roszman1_ratio_denominator_intersection.png`。

A 为解析比值区间相对原独立比值区间的宽度比；B 为新替代界相对第五十四阶段替代界的宽度比；C 为最终交集逐点收紧量；D 明确保留第 5 折 5 个不可用点。

| 问题 | 本阶段可以支持的回答 | 不能推出的结论 |
|---|---|---|
| 是否联合处理 b3 与分母 | 是，固定 x 和负符号域内的解析支撑 | 任意符号或跨零分母也能给有限界 |
| 是否完整联合全部预测参数 | 否，线性支撑与比值支撑可取自不同见证 | 完整四参数非线性全局最优 |
| 20 个可用点是否全部收紧 | 是，最终交集为 20／20 | 任意数据、模型或新 x 都必然收紧 |
| 200 次评价说明什么 | 实现、端点与候选一致 | 候选检查就是全局最优证明 |
| 第 5 折是否有有限界 | 没有，5 点保持不可用 | 可以用低 RMSE 绕过奇异检查 |
| 是否有概率或独立实验结论 | 没有 | 置信度、概率覆盖率、独立模型族或独立实验 |

本阶段解决的是反正切比值分量的联合支撑，不是原生模型全部相关结构的终结。后续若继续研究，应显式处理线性项、比值项与 arctan 的共同极值，或寻找可证明的更紧交集，而不是把当前改进称为全局最优。
