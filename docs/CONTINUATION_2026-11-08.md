## 2. Eckerle4：不同物理数据上的双尾外推

### 2.1 数据与冻结协议

第二个独立数据集来自 NIST Eckerle4 圆形干涉透射率研究，共 35 个观测。原始文件 SHA-256 为 `8ec2133b29a0a7cecbfccd51f7c61ee432f73c460bf5ce7106d672642e57a61e`。

在拟合前冻结 `validation/eckerle4-two-tail-protocol.json`：

- 低尾：\(x\leq410\)，3 个观测；
- 中央训练：\(410<x<480\)，27 个观测；
- 高尾：\(x\geq480\)，5 个观测；
- 高斯模型：\(y=(b_1/b_2)\exp[-\frac{1}{2}((x-b_3)/b_2)^2]+e\)；
- 两个预注册起点、训练均值与线性基线；
- 所有 8 个尾部点均不得用于拟合、选起点或调整阈值。

全数据拟合另用于 NIST 已知答案复核，认证参数与残差标准差均在预注册容差内通过，未把全数据拟合当成留出证据。

### 2.2 双尾结果

| 指标 | 数值 |
|---|---:|
| 中央训练 RMSE | 0.007361491 |
| 低尾 RMSE | 0.000190523 |
| 高尾 RMSE | 0.000248162 |
| 合并留出 RMSE | 0.000228260 |
| 线性基线合并留出 RMSE | 0.136744754 |
| 训练均值基线合并留出 RMSE | 0.098013865 |
| 留出 MAE | 0.000199837 |
| 留出最大绝对残差 | 0.000457900 |

合并留出 RMSE 小于中央训练 RMSE 的 3 倍和线性基线，两个尾部也分别优于对应线性基线，因此预注册判据给出**有限支持**。独立程序从 35 个逐点预测重新计算所有模型、基线、指标和判据，最大预测差为 0。

## 3. cvc5：独立求解器复核 Z3

官方 cvc5 1.4.2 静态二进制已保存在项目隔离目录 `.engines/`，并在 WSL Ubuntu x86_64 上实际运行。官方发布页为 <https://github.com/cvc5/cvc5/releases/tag/cvc5-1.4.2>。二进制和官方 ZIP 均记录 SHA-256，原始 SMT-LIB 和日志全部保留。

| 检查 | cvc5 | Z3 | 解释 |
|---|---|---|---|
| 否定正性定义域的约束 | unsat | unsat | \(b_2>0、b_3\geq0、x\geq0\) 时分母恒正 |
| 无分母约束的反例 | sat | sat | 零分母可达到，定义域不能省略 |
| \(x=0\) 参数非识别性 | sat | sat | 不同参数三元组可产生相同响应 |

cvc5 生成的精确有理数反例为 \(b_1=1/10、a_1=1/5、b_3=1/50、a_3=3/100\)，与 Z3 的非识别性结论一致。双求解器一致只提高这些明确公式的实现可信度，不扩大为一般非线性定理证明。
