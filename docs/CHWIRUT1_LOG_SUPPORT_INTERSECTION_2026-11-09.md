# 前沿共生第五十三阶段：Chwirut1 对数支撑与保守交集

**日期**：2026-11-09  
**文档性质**：利用分母对数的割线与三条冻结切线，在完整三参数椭球上构造对数域保守界，再与第四十四阶段独立包络取交集；不是全局优化、概率区域、独立模型族复现或独立实验。

## 1. 对数恒等式与模型边界

协议提交为 `005c48a`。既有包络使用独立的指数和分母区间，本阶段不是重复复算，而是利用分母对数的凹凸性和三参数协方差耦合构造新界。原生模型保持为 exp(-b1x)/(b2+b3x)，**不改变原生模型**，也不使用 Taylor 替换。

在分母严格为正时，有：

\[
\log f=-b_1x-\log d,\qquad d=b_2+b_3x>0。
\]

所有距离均沿用第四十四阶段的正分母证书和分母区间。Chwirut1 与 **Chwirut2 同研究同模型族**，因此本阶段只是同一研究、同一模型族内部的新区间构造，不是独立模型族或实验室复现。

## 2. 割线上界与三条切线下界

对数分母是凹函数，其区间割线位于函数下方，因此负对数可由负割线控制上界。令割线斜率和截距为 m、q：

\[
-b_1x-\log d\;\leq\;-b_1x-\left[m(b_2+b_3x)+q\right]。
\]

右端是 b1、b2、b3 的线性函数，可在完整椭球上直接计算上支撑，保留参数相关结构。

任意正点 t 的切线位于对数函数上方，因此负对数可由负切线控制下界：

\[
-b_1x-\log d\;\geq\;-b_1x-\left[\frac{b_2+b_3x}{t}+\log t-1\right]。
\]

本阶段预先固定 t 为 d_min、d_center、d_max，分别计算线性下支撑并取三者最大值。取最大下界仍保持保守性，但**不是全局最优**的切线搜索，更不是完整非线性全局最优。

对数上下界指数化后与第四十四阶段独立包络取交集：

\[
I(x)=\left[\max(L_{log},L_{ind}),\ \min(U_{log},U_{ind})\right]。
\]

交集必须非空，并同时包含中心预测和全部候选预测。历史基线不替换、不改写。
