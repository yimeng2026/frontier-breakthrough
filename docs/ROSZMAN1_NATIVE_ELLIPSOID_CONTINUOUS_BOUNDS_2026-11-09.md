# 前沿共生第四十六阶段：Roszman1 原生反正切椭球奇异证书与预测界

**日期**：2026-11-09  
**文档性质**：在显式参数椭球和连续留出区间内，对原生反正切模型进行 x-b4 同号证明与保守包络审计；不是概率区域、置信区间、全参数全域证明、精确有理证明或独立物理实验。

## 1. 区域、同号与解析临界半径

协议提交为 `0e5c8e6`，冻结五个原生参数中心、对应的 4×4 局部协方差矩阵、连续留出区间和半径 4。协方差只用于定义椭球，不构成后验或置信区域。半径 4 是算术选择，不是概率水平。

对中心 c 和正定矩阵 C，使用椭球 E={(θ-c)^TC^(-1)(θ-c)≤4^2} 及支撑恒等式 max g^T(θ-c)=4√(g^TCg)。分母为 d=x-b4，其支撑只与 C_b4b4 有关：

\[
d_{\min}(x)=x-\hat b_4-4\sqrt{C_{44}}，\qquad
d_{\max}(x)=x-\hat b_4+4\sqrt{C_{44}}。
\]

两个界均为 x 的仿射函数，因此闭区间极值在端点。两端 d_max 均严格小于 0 才认证负号，两端 d_min 均严格大于 0 才认证正号；否则不生成有限包络。数值零区按尺度拒绝，避免把约 1e-14 的舍入残差误当成严格符号。

当两端中心同号时，解析奇异临界半径为：

\[
\rho=\min\!\left(\frac{|x_{\mathrm{left}}-\hat b_4|}{\sqrt{C_{44}}}，
\frac{|x_{\mathrm{right}}-\hat b_4|}{\sqrt{C_{44}}}\right)。
\]

只有半径严格小于 rho 才能认证同号；等于临界值时不再具有严格同号。五折均通过“半临界值接受、精确临界值拒绝”的负例检查。

## 4. 原始 arctan 包络与宽度

对通过同号检查的点，先由 b3_min、b3_max 与 d_min、d_max 的四个比值组合取得 z_min 和 z_max，再利用 arctan 单调性：

\[
A=b_1-b_2x，\qquad
f_{\min}=A_{\min}-\frac{\arctan(z_{\max})}{\pi}，\qquad
f_{\max}=A_{\max}-\frac{\arctan(z_{\min})}{\pi}。
\]

线性项 A 同时计算 b1、b2 的两个端点组合，保留 x 为负时的正确方向。整个过程使用原始 arctan 函数，没有 Taylor 替换；独立放松允许保守但偏宽的包络。

## 6. 证据边界与后续义务

| 问题 | 本阶段可以支持的回答 | 不能推出的结论 |
|---|---|---|
| 半径 4 是否所有折同号 | 否，第 5 折跨零，其他四折为负号 | 用前四折结果代替全折证明 |
| 第 5 折能否生成有限包络 | 不能，必须保留 5 个不可用点 | 用 arctan 有界性代替分母非零证明 |
| 包络是否使用 Taylor 近似 | 没有，使用原始 arctan 函数 | 把局部线性化当成原生模型 |
| 20 点覆盖是否是概率覆盖 | 不是，只是中心一致性检查 | 置信度、后验概率或校准分数 |
| 上界是否高信息量 | 不必然，最大宽度 0.867292，最大上界 0.443391 | 有界就等于高精度或物理正确 |
| 是否为精确有理证明 | 不是，采用 80 位精度和外向数值舍入 | 精确有理代数证书 |

后续若要扩大可用区域，必须针对 b4 与 x 的相对位置重新约束参数区域，并保留跨零反例。若要为 Roszman1 建立更紧的原生界，还需要处理 b3、b4 的联合非线性极值，而不是把当前独立放松误当作最优包络。当前结果不构成独立物理实验、概率区间或物理参数内生性证明。
