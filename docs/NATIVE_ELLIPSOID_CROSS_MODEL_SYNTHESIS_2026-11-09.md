# 前沿共生第四十九阶段：三模型原生椭球包络受限综合

**日期**：2026-11-09  
**文档性质**：对 Chwirut1 原生指数、Roszman1 原生反正切和 ENSO 原生 Fourier 的半径 4 冻结结果进行只读重算与受限综合；不是新拟合、概率覆盖、跨模型绝对排名、联合非线性最优证明或独立物理实验。

## 1. 输入、复算义务与不可合并原则

协议提交为 `4fbfd66`。三份输入分别为第四十四、四十六和四十七阶段的原生连续椭球结果，对应收据全部通过，收据中的结果哈希与冻结文件一致。本阶段重新核对逐点上下界、中心预测、实际残差、不可用空值、包络坐标、逐折计数、宽度与残差上界，不重拟合、不改中心或协方差。

共同数值半径 4 不意味着三个椭球具有相同物理含义。参数、响应变量、数据设计和量纲不同，因此不跨数据集合并原始宽度、残差上界、RMSE、参数或协方差，也不建立统一稳定性分数。第四十八阶段的半径网格不混入本基线。

## 4. 只在各自数据集内部归一化

令 W_d 为数据集 d 的可用包络宽度集合，B_d 为对应残差上界集合。对可用折 f，定义两个描述性比值：

\[
R^{(w)}_{d,f}=\frac{W^{\max}_{d,f}}{\operatorname{median}(W_d)}，
\qquad W^{\max}_{d,f}=\max_{x\in f}W_d(x)。
\]

\[
R^{(b)}_{d,f}=\frac{B^{\max}_{d,f}}{\operatorname{median}(B_d)}，
\qquad B^{\max}_{d,f}=\max_{x\in f}B_d(x)。
\]

分母始终来自同一个数据集。比值只描述折内相对离散程度，不是概率、校准不确定性、物理效应大小、稳定性得分或跨模型胜负。不可用折的两个比值均为空，不补零。

## 5. 中心一致性、模型病征与四联图

**402／402** 的中心预测均落在可用包络内，实际残差均未超过其上界，违规数为 0，中心包络不匹配数为 0。这不是概率覆盖率，也不是外部科学验证：中心本来就位于所选椭球内，实际残差上界也是由同一观测和包络计算的算术量。

Chwirut1 与 **Chwirut2 同研究同模型族**，不能称为独立模型族或独立实验室复现。ENSO 正周期不证明唯一物理周期；原有“默认优化器未达原容差、认证参数前向通过”继续作为已知答案诊断保留，不进入留出证据。三类包络均为模型特有的保守放松，不是联合非线性最优解。

## 6. 证据边界与后续义务

| 问题 | 本阶段可以支持的回答 | 不能推出的结论 |
|---|---|---|
| 全部点是否保留 | 是，407 点均有明确状态 | 只用 402 个可用点代表全部 |
| 不可用位置 | Roszman1 第 5 折，5 点 | 低 RMSE 即可获得有限界 |
| 实际包络总数 | 210，不是理论点数 407 | Chwirut1 重复距离被重复计数 |
| 是否跨模型合并原始指标 | 没有，原始单位各自保留 | 原始宽度可直接排名 |
| 是否有统一评分 | 没有统一稳定性评分 | 比值就是概率或物理效应 |
| 是否联合最优 | 没有，只复算既有保守包络 | 联合非线性极值已经解决 |
| 是否独立验证 | 没有，只读冻结结果并核对收据 | 新实验、独立模型族复现或全域安全 |

后续若提高跨模型比较的解释力，应增加真正独立的模型族、实验条件和外部观测，而不是扩大归一化指标。若收紧包络，应分别处理各模型的联合非线性极值与定义域，不能把某一模型的证书移植到另一模型。
