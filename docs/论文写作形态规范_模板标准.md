# 论文写作形态规范_模板标准

## 文档头

```markdown
# {中文标题}
**{English Title}**
---
> **作者** | 千界花园学术系统
> **单位** | 千界花园学术系统 · 前沿共生计划
> **日期** | {YYYY年M月}
> **分类** | {领域} · {方法} · 研究简报
---
```

## 必要结构

1. 摘要：单段，包含真实数值和明确边界。
2. 关键词。
3. 一、引言，含 1.1 研究背景、1.2 数据与方法来源、1.3 研究挑战、1.4 本文的研究动机与内容安排。
4. 二、理论模型：只定义实际使用的标识映射、计算公式和比较规则。
5. 三、数值结果：每幅图后必须有解释；区分观测值、计算值和推断。
6. 四、讨论：必须含反例、方法限制和不能推出的结论。
7. 五、结论：不超出证据。
8. 参考文献：只列实际使用或可回查的来源。
9. 附录：核心计算和复现路径。

## 纪律

- 不使用 mock 数据；所有数值来自公开快照或实际运行。
- 不把跨库一致写成独立实验复现，不把单一 assay 写成普遍常数。
- 文档性质统一标注“研究简报／预印本草案，未同行评议”。
- 作者、实验、引用、审稿状态不得虚构；花园初稿必须经数值和来源核验。
- 数学符号、单位、数据库 ID 和实体编号保持全文一致。
