| 折 | 候选 RMSE | 三次基线 RMSE | 椭球可用点 | 盒可用点 | 连续椭球安全 | 连续盒安全 |
|---|---:|---:|---:|---:|---|---|
| 1 | 200.427442 | 248.093874 | 50 | 50 | 是 | 是 |
| 2 | 10211.473429 | 69.371879 | 40 | 0 | 否 | 否 |
| 3 | 34.081526 | 59.690062 | 50 | 44 | 是 | 否 |
| 4 | 49.039022 | 63.067092 | 50 | 50 | 是 | 是 |
| 5 | 40.919288 | 209.558980 | 0 | 0 | 否 | 否 |

第 2 折候选 RMSE 明显高于三次基线，第 5 折没有任何可用椭球界。即使其余四折候选 RMSE 低于对应三次基线，也不能据此宣称候选普遍优于基线；三次基线本身也不是原生模型的公平留出近似。

250 点中共有 190 点可给出椭球界，60 点不可用；这 190 个适用点未发生实际残差越界。最大残差上界为 4896.967582，中位数为 59.003611，最大预测平移上界为 4777.531896。上界可用不等于上界狭窄，更不等于预测准确。

三个数据集合计 365 点，其中 305 点有可计算椭球界、60 点不可用；305 个适用点均未发生覆盖违规。15 折中 13 折连续椭球安全，7 折独立盒连续安全，优化失败为 0。这里的 305／365 只是当前三个数据集的可计算性描述，305 个适用点的零违规也只是确定性检查，二者都不是概率覆盖率、普适外部成功率或未来预测保证。

逐点残差上界采用下式，不能把其中的观测残差项删掉后再宣称同样的逐点覆盖：

\[
|y-f_\delta(x)|\leq |y-f(x)|+\frac{|N(x)|R_E(x)}{|D(x)|(|D(x)|-R_E(x))}。
\]

## 5. 这一反例改变了什么

通用驱动证明了自身的可复用性，但也证明代码复用与科学有效性是两条不同的轴。Gauss1 没有被用于设计此前区域，却仍然出现预测失败、连续证明失败和逐点界不可用。这一结果否定了“采用同一驱动即可自然延续 Filip 与 MGH17 全部良好结果”的强解释。

后续研究应把候选结构适配、连续分母安全、逐点可计算性和上界宽度分开验收。若要改变候选次数、半径、起点或参数区域，必须另立协议并保留本次失败，不能在看到 Gauss1 结果后静默修改本阶段规则。
